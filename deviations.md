## D1 — "commit live" at a first appearance (3b)
Prereg: `git rev-list -1 --first-parent --before=<FA UTC> main`. Landings here are fast-forwards of branches whose commits carry earlier committer times, so that command can return a commit that was not yet on main at the instant (at T2 it returns 88f2b00, which main's reflog shows merged on 2026-10-12, after T2). Used instead: main's reflog (`git log -g main`) to find main's tip at the instant, cross-checked with rev-list. T1 2026-10-02 → rev-list 015b89b (local reflog dd27887; 015b89b was pushed from the cloud lane on 10-01, one commit later; 015b89b used, the wider tree, which can only make 3b fail more often). T2 → 993d6f7 (CARRY, merged 10-12). T3 2026-11-09 → c034eae. Effect: none on any 3b verdict unless noted per request.
## D2 — First appearance excludes early life-aspiration lines
Prereg defines first appearance as the earliest agent message naming the capability "as something the agent asks to have built (a wish or a specification)". A few months-earlier lines name a capability inside a list of life aspirations, not as a build (e.g. 2026-05-14, message 4140, wanting a byline and a podcast). Counting those would date requests from before the loop existed and move them across batches. Rule applied: such lines are recorded as precursors in the private census; the first appearance is the earliest message asking for the capability as something to be built for itself. Affects #29, #35 (precursor 4140), #52 (precursor 29658, 2026-10-15). Reported in the census.

Eleven requests (#25, #31, #37, #40, #42, #45, #48, #54, #57, #58, #61) touch topics this series' privacy rules bar, and testing 3a for them would mean reading windows those rules close. ## D4 — Kit provenance: "design decisions" were not a preregistered ruling category
The prereg classifies added rulings as safety, gating, engineering method, cost, privacy or class gates, operator controls, or other, and S1 requires ≥ 50% to be engineering method or gating. Reading the rulings shows a large class the list did not name: decisions about what is built (tool signatures, DDL and columns, sources, routes and pages, cadences, caps). Under the stricter reading (design ≠ method; design counted as other), keyword classification gives gating 63 + engineering method 60 = 123 of 281 rulings (43.8%), so S1's fourth condition fails and S2's conditions hold (≥ 60% of named items carried: 315/319; rulings add identifiers the agent did not name in 35 of 35 builds, median 20). Under the looser reading (design counted as engineering method), S1's fourth condition passes. The stronger sentence is therefore not carried unambiguously; the article uses S2 and reports both readings. Classification is keyword-based (work/scripts/kit_prov.py), with the 54 rulings it left unclassified read by hand: nearly all are design decisions or scope cuts ("NOT HERE", "[its] five points and nothing more", "no pull requests", "[its] rule, made stricter by default").
## D5 — The second coder was first shown fewer requests than the preregistration required
The preregistration withholds from the second coder only "requests that cannot be anonymized enough to show a subagent", which is three requests that could not be shown at all (#37, #42, #45). The first run withheld eleven, the article's whole withheld bucket, and showed 48. At the operator's mid-run instruction (2026-11-09), the other eight (#25, #31, #40, #48, #54, #57, #58, #61) were shown to a fresh instance of the second coder, with the same rubric and nothing else, as mechanism-only text: the agent's own words where they describe the mechanism, with everything under the article's wall removed (work/coding_input_8.txt, swept with a planted-term control). Because the first coder wrote that text, the second coder's input for these eight passed through the first coder's hands. Result: the coders agree on all eight; κ 0.939 on 48 becomes 0.946 on 56; no final code changes; the broad reading is 47 of the 56 double-coded requests (47 for each coder before resolution) and 50 of 59 with the three coded by me alone, all three broad.
